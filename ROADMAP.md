# Hoja de ruta de LaguCAM

- [ ] **F0 - Fundamentos:** proyecto Qt 6/C++20, Git limpio, licencia, documentos y CI.
- [ ] **F1 - Aplicacion y visor 3D:** interfaz modular, carga STL/STEP, navegacion y proyectos.
- [ ] **F2 - CAM 3 ejes:** herramientas, bruto, origen, planeado, perfilado, cajeras, desbaste y acabado.
- [ ] **F3 - Verificacion y postprocesadores:** trayectorias verificables, simulacion y G-code.

## Criterio de finalizacion

Cada tarea debe compilar, superar pruebas pertinentes y quedar documentada.
Antes de mecanizar en hardware, validar la salida NC con el control y una maquina concreta.
