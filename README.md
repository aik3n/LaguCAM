# LaguCAM

LaguCAM es un proyecto de software CAM libre y multiplataforma para CNC.

## Estado
Estamos en H0.1: definicion del metodo de trabajo. No hay funciones CAM validadas.

## Principios
- Discutir antes de implementar.
- Codigo sencillo, robusto y mantenible.
- Software libre y multiplataforma.
- Documentar decisiones y verificar cambios.
