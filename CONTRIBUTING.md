# Contribuir a LaguCAM

- Crear una rama por cambio; no desarrollar directamente en `main` cuando el proyecto crezca.
- Usar solicitudes de cambios (pull requests) y describir pruebas realizadas.
- Mantener el codigo portable entre Windows, Linux y macOS.
- Evitar dependencias propietarias y documentar licencias de bibliotecas.
- No subir `build/`, archivos `*.user`, datos personales ni binarios generados.
- Para cambios del motor CAM, incluir casos de prueba geometricos y limites conocidos.

La licencia del repositorio todavia debe formalizarse.
